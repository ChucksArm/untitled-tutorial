## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn
- Git
- AWS account (free tier eligible)
- Vercel account

### Quick Start

```bash
# Clone this repo
git clone https://github.com/ChucksArm/untitled-tutorial.git
cd untitled-tutorial

# Install dependencies
npm install

# Start learning with Module 1
npm run learn:module1

# Build the portfolio project
npm run build:portfolio

# Deploy to Vercel
vercel
```
